# 🎨 Computação Gráfica

> Repositório com os trabalhos desenvolvidos durante a disciplina de **Computação Gráfica**, no primeiro semestre de 2026, do curso de **Ciência da Computação** da **PUC Minas**.

---

## 📖 Sobre

Este repositório reúne os projetos e atividades práticas realizados ao longo da disciplina de Computação Gráfica. O objetivo da disciplina é apresentar os fundamentos teóricos e práticos da área, incluindo modelagem, renderização, transformações geométricas, iluminação e outros tópicos essenciais para a criação de imagens e cenas digitais.

## 📂 Estrutura do Repositório

Os trabalhos serão organizados em pastas conforme forem desenvolvidos ao longo do semestre. Cada pasta conterá o código-fonte, assets e uma breve descrição do respectivo trabalho.

---

## 🚀 Tecnologias Utilizadas

- **OpenGL / WebGL** — Renderização gráfica
- **GLSL** — Linguagem de shaders
- **C / C++** — Implementação dos projetos
- Outras ferramentas e bibliotecas conforme necessidade de cada trabalho
